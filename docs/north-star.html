Zero

A quiet assistant that lives on your Mac, speaks plainly, and never makes you wonder whether it heard you.

The rule we design to

Every surface answers three questions without being asked: is it alive, did it hear me, and what did it do. The previous prototype failed on the third — users refused to read raw tool calls — and the menubar failed on the first, showing a ready light for an agent that was never running. Those two failures cost more trust than any missing feature.

Six states, and what each one says out loud

This is a lifecycle, so the order carries information: a person meets these in sequence. Every surface — menubar, phone, terminal — renders the same six, and never invents a seventh.

asleep Zero isn’t running — and how to start it. Detected by a stale status file, so a dead agent can never look ready.
waking Waking up… — “Loading its brain. About a minute the first time.” Written before the model loads, not after.
idle Ready — idle means idle. It does not generate, watch, or speak unprompted.
thinking Thinking… — with a live tail of its reasoning, so a twenty-second wait looks like thought.
executing Working on it… — one action at a time, journaled before and after.
error Something went wrong — said in a sentence, with what to try next. Never a stack trace, never silence.

Phone — the surface you’ll actually use

Grayscale-first for the Daylight DC-1’s reflective panel: contrast comes from fill and border, never hue. Adapts to the Pixel Fold’s two panels at the canonical breakpoints — three panes unfolded, one plus a drawer folded.

What the first Zero got right

Worth carrying forward: it had a voice, and an information architecture that matched how a person thinks about their life rather than how the software is built.

its own words, 2026

“I’m here to help you navigate your digital world — whether that means tackling complex projects, organizing your files, or just exploring what’s possible.”

Warm, first-person, unhurried. The current Zero speaks in one plain sentence per turn; this is the register to grow into.

Where we are

done
  • Speaks one plain sentence every turn — successes and failures alike
  • Liveness: a dead agent shows grey, never green
  • Reasoning streams while it thinks
  • Remembers across restarts, and says so
  • zero command with a first-run greeting
  • Shadow mode by default; going live is a human’s hand only
next
  • One .app — no terminal to install or start it
  • Cold-start progress outside the terminal
  • Approve-before-acting, so live mode is safe for family
  • A phone that talks to the agent, not just to models
honest gaps
  • It never speaks first — no proactivity at all yet
  • More literal than it should be: “my Downloads folder” beats a vague description
  • No reminders, calendar, or scheduled work — it will tell you so rather than pretend
  • The journal keeps everything you type, in plain text, forever
